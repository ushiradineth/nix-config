# Visual and interaction character

Choose one purposeful intervention on the requested target. Preserve the project's visual world,
real content and unaffected behavior. Strong expression on a portfolio and precision on a dense
settings screen are different forms of ambition.

## Colorize

Audit existing brand, neutral and semantic colors first. Decide whether color will establish
hierarchy, meaningful categories, state or atmosphere. Apply relationships through semantic tokens
so hover, focus, disabled and relevant themes remain coherent.

Check contrast and meaning in the rendered combinations. Do not rely on hue alone for status.
Unrelated saturated patches and decorative gradients are not a strategy. Existing brand choices
outrank generic palette preferences; do not silently replace them.

## Bolder

Name why the target reads flat: weak hierarchy, timid scale, no focal point, unconvincing imagery or
an indistinct composition. Amplify that dimension inside the existing system. A larger type role,
more decisive crop or clearer structural contrast may do more than several effects.

Keep the surrounding page and product claims intact. “Make this section bolder” does not authorize a
page redesign. If the skeleton stays generic beneath the decoration, revisit the composition.

## Quieter

Reduce competing accents, unnecessary weight, containers and motion. Establish a clear leading
element and supportive secondary material. Retain identity, legibility, state differences and useful
information; lowering all contrast is not restraint. Judge the result in the full surrounding page.

## Animate

Give motion a job: feedback, state change, continuity, spatial relationship or a focal moment the
surface earns. Define what moves, why, when and how it interrupts before choosing an effect.

Use the existing motion runtime. Keep routine operational transitions quick and the interface usable
at rest; do not hold content invisible while it waits for choreography. Prefer properties that avoid
unnecessary layout work. More ambitious masks, filters or shaders need observed runtime headroom, a
meaningful role and a fallback.

Respect reduced-motion preferences with an intentional simpler alternative. Preserve state feedback
and reading order. Check keyboard/focus, interruption, repeated activation, scrolling and
performance as applicable. Do not add a dependency or page-wide reveal system for a small state
transition.

## Delight

Pick one product-specific moment that improves comprehension, confidence, motivation or recovery. It
may be humane copy, a considered interaction or a restrained visual detail. Animation is optional.
Keep repeated work efficient and stressful moments clear. Never fake progress, delay success or
block a task to stage a flourish. Use the animate guidance if motion is part of the idea.

## Overdrive

Use only for an explicit request for extraordinary visual/interaction work. Develop a few concrete
directions and explain the interaction and performance costs. If the user delegated the choice or
already specified it, proceed; otherwise resolve the consequential direction before building it.

Use techniques such as scroll-linked composition, shared-element transitions, rich data interaction,
canvas or shaders when they express the idea rather than advertise the technology. Maintain a usable
baseline without the enhancement. Verify the actual result, input modes, reduced motion, runtime
cost and failure/fallback state. Do not add spectacle to operational UI merely because the toolchain
permits it.

Finish once the requested expressive change works coherently. [Polish](finish.md) resolves remaining
consistency issues; it does not justify another round of effects.

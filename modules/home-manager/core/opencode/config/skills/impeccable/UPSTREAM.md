## Local changes

The local router and grouped references adapt the design decisions to the existing OpenCode harness.
They replace binary context loading, detector calls, mandatory multi-agent panels, fixed interviews,
score templates and finish handoffs with task-scoped context, native tools and the parent Jiyu
integration/review boundary. References load by current need instead of registering every verb as a
global skill. Native platform prose is retained, with repository formatting.

The supplied brief and project design system remain authoritative. Anti-pattern guidance is a reason
to make a deliberate choice rather than a universal veto on a requested style. Verification is
driven by affected states and unresolved evidence rather than an arbitrary number of passes.

No upstream engine, bootstrap/download script, live-browser bundle, provider hook, package install
or detector service is included. No Paperclip export or live binding is added. Legacy project-local
Impeccable skills remain available; the managed router selects this entrypoint for new UI tasks
instead of stacking the older workflows.

To update, compare the candidate upstream revision and full affected references with this pin;
preserve notices and review the local decisions rather than overwriting the adaptation. Verify
native discovery, command ownership and realistic UI/non-UI routing. Packaging tests alone do not
prove future visual quality or model routing reliability.

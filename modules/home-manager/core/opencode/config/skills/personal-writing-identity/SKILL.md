# Personal writing identity

Preserve the user's meaning and concrete facts. Read the voice reference and the applicable channel
guidance before drafting:

- [Voice signature](references/voice-signature.md).
- [Channel playbooks](references/channel-playbooks.md).

Use the supplied examples to calibrate rhythm and tone. Infer a reasonable channel and audience from
the request; ask only when the choice changes the deliverable. Draft in the current session.

Use `unslop` to remove generic AI phrasing while preserving deliberate voice choices. Exact facts,
claims, quotations, code, commands, identifiers and links take precedence over style. Keep legal,
security and incident prose neutral where personality would reduce clarity.

Return the finished copy. Include draft/audit alternatives only when requested. This skill does not
require a writer agent, a second prose pass on routine status updates, or permission to publish.

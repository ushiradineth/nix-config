# Arena

Use for competing approaches, not coverage of different slices. State the shared brief, constraints,
done check and scoring criteria before starting. Use two candidates by default; more need a reason.

Give each candidate the same context and a separate scratch directory or worktree. Include relevant
uncommitted changes in its baseline. Writers cannot share files. Candidates return their artifact,
rationale and exact checks; they do not launch agents or alter the main working tree.

Use actual configured models. Inheritance is valid; do not claim diversity when every candidate uses
the same model. If delegation is unavailable, compare prototypes inline and state that limitation.

Read every candidate. Prefer demonstrated correctness, simpler ownership and lower reader load over
a persuasive report. Pick a base, integrate only useful compatible ideas, and verify the result
against the original checks. Do not average incompatible designs or keep multiple production paths
merely because they were candidates. Report the choice and its evidence.
